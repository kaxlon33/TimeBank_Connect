# TimeBank Connect

A community time-banking platform: members exchange skills using time credits (1 hour of help = 1 credit) instead of money.

Coursework project for Advanced Full Stack Development.

## Stack

| Part | Technology |
|---|---|
| Frontend | React 18, TypeScript, Vite (`apps/web`) |
| Backend | PHP 8.2, Laravel 12 REST API (`apps/api`) |
| Auth | Laravel Sanctum (SPA cookie), Member and Admin roles |
| Database | MySQL (XAMPP) with Eloquent ORM and migrations |
| Third-party APIs | OpenStreetMap Nominatim, REST Countries |
| Version control | Git and GitHub (issues, labels, milestones) |

## Project layout

```
apps/web    React + TypeScript single-page app
apps/api    Laravel REST API
```
